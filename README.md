# BUS-312 Airbnb End-To-End Project

## What I Use
- **Excel/Spreadsheets**: Data cleaning and analysis
- **PowerPoint**: Presentation and visualization
- **Data Analysis Tools**: For processing Airbnb NYC data

## What I Do
This project involves an end-to-end analysis of Airbnb listings in New York City. The workflow includes:
- Cleaning messy raw data
- Processing and transforming data for analysis
- Generating insights from the dataset
- Presenting findings through reports and presentations

## What I Find
- Analysis of Airbnb NYC market trends
- Key insights from the cleaned dataset
- Comprehensive findings documented in the written report
- Visual representations in the presentation
